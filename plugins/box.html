Box 颜色盒 ​

ewColorPickerBox 是用户第一眼看到的控件：一个显示当前颜色的方形触发器。点击它开合颜色面板。

项值
包@ew-color-picker/box
pluginNameewColorPickerBox
applyOrder未显式声明（按注册顺序执行，聚合包中排第 2）
挂载点root（.ew-color-picker）
访问实例core.plugins.ewColorPickerBox

配置项 ​

Box 读取以下 options：

配置类型默认值说明
defaultColorstring''初始颜色，同时作为「清空」后的还原色
sizestring | number | { width, height }'normal'色块尺寸，详见下文
disabledbooleanfalse禁用后不可点击，面板也不会展开
readonlybooleanfalse只读：阻止点击（与 disabled 同样不响应），仅保留视觉样式
hasBoxbooleantrue设为 false 时不渲染色块
boxNoColorIconstring''无颜色时自定义图标（HTML 字符串）
boxHasColorIconstring''有颜色时自定义图标（HTML 字符串）
classNamestring''追加到 .ew-color-picker-box 上的额外类名
stylestring | Record<string,string>''直接内联到色块的样式
onClick(plugin) => void—点击色块时的回调，参数为 Box 插件实例
onMouseEnter(plugin) => void—鼠标移入回调
onMouseLeave(plugin) => void—鼠标移出回调

size 的三种写法 ​

写法示例结果
预设关键字size: 'mini'mini=20px、small=24px、normal=32px、medium=36px、large=40px
数字size: 48宽高均为 48px
对象size: { width: '60px', height: '36px' }自定义宽高（数字会自动补 px）
CSS 字符串size: '5rem'原样使用

图标尺寸会跟随色块尺寸自动缩放：

size图标尺寸
mini12px
small14px
normal16px
medium18px
large20px
数字 / 对象取较短边的 50%

图标颜色自适应 ​

默认图标颜色不是写死的，而是按背景色相对亮度计算：

  • 亮度 > 0.5（浅色背景）→ #333333
  • 否则 → #ffffff
  • 半透明颜色按「叠加在白色底上」的实际呈现色计算

因此 #fff 上会显示深色箭头，#000 上会显示白色箭头，无需手动配置。

new ewColorPicker({
  el: '#app',
  boxNoColorIcon: '<svg viewBox="0 0 24 24">…</svg>',

事件与回调 ​

Box 自身不触发事件，点击时按当前状态直接调用：

ts
if (picker.pickerFlag) {
  picker.hidePanel(togglePickerAnimation, pickerAnimationTime)
} else {
  picker.showPanel(togglePickerAnimation, pickerAnimationTime)
}

监听颜色或开合状态请使用核心事件：

ts
picker.on('toggle', (isOpen) => console.log('面板开合：', isOpen))
picker.on('change', (color) => console.log('颜色：', color))

完整示例 ​

html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <link rel="stylesheet" href="/node_modules/@ew-color-picker/style/dist/index.css" />
    <link rel="stylesheet" href="/node_modules/@ew-color-picker/style/dist/input-number.css" />
  </head>
  <body>
    <div id="app"></div>
    <script src="/node_modules/@ew-color-picker/ew-color-picker/dist/index.min.js"></script>
    <script>
      const picker = new ewColorPicker({
        el: '#app',
        defaultColor: '#6366f1',
        size: 'large',
        onMouseEnter: () => console.log('鼠标移入色块'),
        onMouseLeave: () => console.log('鼠标移出色块'),
        onClick: (box) => {
          console.log('点击了色块', box.hasBox)
        },
      })
    </script>
  </body>
</html>
