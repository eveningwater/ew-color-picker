Panel 颜色面板 ​

ewColorPickerPanel 负责最核心的取色区域：一张二维渐变面板，横轴是饱和度（S），纵轴是明度（V），拖动光标即可改色。

项值
包@ew-color-picker/panel
pluginNameewColorPickerPanel
applyOrderPost
挂载点panelContainer
访问实例core.plugins.ewColorPickerPanel

配置项 ​

配置类型默认值说明
hasPanelbooleantruefalse 时不渲染二维面板
ewColorPickerPanelboolean | objecttrue兼容写法：false 等价于关闭面板；对象形式可合并面板配置
hueDirection'horizontal' | 'vertical''vertical'影响面板计算宽度（水平布局更宽）
alphaDirection'horizontal' | 'vertical''vertical'同上，两者都水平时面板宽 320px
autoPanelPositionbooleanfalse是否根据触发器位置自动定位面板
panelPlacementstring'bottom'自动定位时的方向，见下表
ewColorPickerBoxbooleantrue自动定位必须是 true（需要读取 Box 尺寸）
alphaboolean由插件是否存在决定有无透明度插件会影响默认颜色格式
disabledbooleanfalse禁用后拖拽不生效

panelPlacement 取值 ​

方向对齐
top-start / top / top-end面板在上方
bottom-start / bottom / bottom-end面板在下方
left-start / left / left-end面板在左侧
right-start / right / right-end面板在右侧

带 -start / -end 时按触发器边缘对齐，不带后缀时居中对齐。面板与触发器间距固定 5px，超出视口会自动翻转/内收。

面板宽度规则 ​

hue 方向alpha 方向面板宽度
垂直垂直285px
水平垂直（或反之）约 302px
水平水平320px

高度固定 180px，通过 CSS 变量 --panel-width / --panel-height 注入。

实例方法 ​

ts
const panel = picker.plugins.ewColorPickerPanel
1
方法签名说明
render() => void重建面板 DOM（会移除旧面板）
updateCursorPosition(saturation: number, value: number) => void把光标移动到 S/V 对应位置（0–100）
updateColor(saturation: number, value: number) => void按 S/V 计算新颜色并调用 core.setColor()，随后 trigger('change')
updateHueBg(hue?: number) => void更新面板纯色底；不传则取当前颜色色相
calculateContainerSize() => void计算容器尺寸（隐藏状态下会临时离屏测量）
handleAutoPosition() => void按 panelPlacement 计算并应用面板位置
calculatePosition(position, align, boxWidth, boxHeight) => { left, top }纯计算，不写 DOM
adjustForViewport(root, left, top) => { left, top }视口边界修正
destroy() => void移除面板与事件

属性 ​

属性类型说明
panelHTMLElement | null面板根节点
cursorHTMLElement | null光标节点
whitePanel / blackPanelHTMLElement | null白/黑渐变层
panelWidth / panelHeightnumber当前面板尺寸
isHueHorizontal / isAlphaHorizontalboolean方向标记
isDraggingboolean是否正在拖拽

手动改色 ​

ts
// 饱和度 50%，明度 80%
picker.plugins.ewColorPickerPanel.updateColor(50, 80)
1
2

注意 updateColor 内部已经调用了 core.setColor() 并触发 change，不需要再调用一次。

交互行为 ​

操作行为
点击面板光标跳到点击位置并立即改色
按住拖拽节流 16ms（约 60fps）连续改色
触摸滑动与鼠标拖拽一致
颜色被其他插件修改监听 change 自动同步光标与底色

updateColor 会先取当前颜色；若为空或包含 NaN，会回退到红色（alpha 开启时为 rgba(255,0,0,1)）并先 setColor，保证面板始终有可计算的颜色。

事件 ​

Panel 不定义自己的事件类型，改色时：

ts
core.setColor(newColor)
core.trigger('change', newColor)
1
2

因此监听 change 即可拿到面板拖动产生的颜色：

ts
picker.on('change', (color) => console.log(color))
1

完整示例 ​

ts
import ewColorPicker from '@ew-color-picker/ew-color-picker'
import '@ew-color-picker/style/dist/index.css'
import '@ew-color-picker/style/dist/input-number.css'

const picker = new ewColorPicker({
  el: '#app',
  defaultColor: '#22c55e',
  hueDirection: 'horizontal',
  alphaDirection: 'horizontal',
  autoPanelPosition: true,
  panelPlacement: 'bottom-start',
})

// 3 秒后把光标拖到「低饱和、低明度」
setTimeout(() => {
  picker.plugins.ewColorPickerPanel.updateColor(20, 30)
}, 3000)
