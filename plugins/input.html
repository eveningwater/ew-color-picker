Input 颜色输入框 ​

ewColorPickerInput 渲染一个文本输入框，允许用户直接键入颜色值。输入合法颜色后回车或失焦即改色；非法输入不会污染当前颜色。

项值
包@ew-color-picker/input
pluginNameewColorPickerInput
applyOrderPost
挂载点panelContainer
访问实例core.plugins.ewColorPickerInput

配置项 ​

配置类型默认值说明
hasInputbooleantruefalse 时不渲染输入框
disabledbooleanfalse禁用输入框
changeColor(rgba: string) => void—输入合法颜色并改色后的回调，参数为 rgba() 字符串

输入框的显示内容由当前模式决定：Hex 模式显示 hex，RGB 模式显示 rgb()/rgba()，HSL 模式显示 hsl()/hsla()。模式切换由 ColorMode 管理。

实例方法 ​

ts
const input = picker.plugins.ewColorPickerInput
1
方法 / 属性签名说明
enableInput(enable = true) => void显示/隐藏输入框
hasInputboolean（getter/setter）setter 会立即渲染或移除 DOM
setValue(value: string) => void直接设置输入框文本（不改颜色）
getValue() => string读取输入框当前文本
setDisabled(disabled: boolean) => void切换禁用态，会同步 ew-input-disabled 类
update(color: string) => void按当前模式格式化并写入输入框
onInputColor(value: string) => void处理输入值；内部防抖 300ms
inputHTMLInputElement | null输入框 DOM

典型用法 ​

ts
// 让输入框显示当前颜色（内部已自动处理，一般无需手动调用）
picker.plugins.ewColorPickerInput.update(picker.getColor())

// 直接读取用户输入
console.log(picker.plugins.ewColorPickerInput.getValue())

// 禁用
picker.plugins.ewColorPickerInput.setDisabled(true)

输入校验 ​

输入结果
#f00、#ff0000、#ff000080合法，按当前插件组合转换为 rgba 或 hex
rgb(255,0,0)、rgba(255,0,0,0.5)合法
hsl(0,100%,50%)、hsla(...)合法
空字符串合法（表示清空颜色）
其它非法，不触发改色；部分场景会 warn

输入事件防抖 300ms，避免每个按键都触发整棵插件树的同步。

改色成功后：

完整示例 ​

ts
const picker = new ewColorPicker({
  el: '#app',
  defaultColor: '#0ea5e9',
  hasInput: true,
  changeColor: (rgba) => console.log('用户输入了：', rgba),
})

picker.on('change', (color) => {
  console.log('当前颜色', color)
})
