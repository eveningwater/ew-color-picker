24. UMD 全量引入（ew-color-picker）

通过普通 script 标签加载 ew-color-picker/dist/index.min.js，全部插件已内置，无需构建工具。

script 标签用法
<link rel="stylesheet" href="https://unpkg.com/@ew-color-picker/style/dist/index.css">
<script src="https://unpkg.com/ew-color-picker/dist/index.min.js"></script>
<script>
  const picker = new ewColorPicker('#picker')
</script>
颜色: 无
当前页面直接引用仓库内的 UMD 产物，未经过模块打包。
