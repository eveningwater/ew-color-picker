回调 ​

回调是配置对象中的函数字段，与事件不同：回调一个事件类型只能配置一个，而事件可以注册多个监听器。回调由具体插件在合适的时机直接调用。

核心回调 ​

changeColor ​

颜色变化时调用，由 setColor() 直接调用。

ts
new ewColorPicker({
  el: '#picker',
  changeColor(color: string) {
    console.log(color)
  },
})

回调 vs 事件 ​

维度回调事件
数量每种一个可注册多个
注册方式构造配置on / once
解绑需 updateOptions 覆盖off
调用者具体插件直接调用插件 / 核心 trigger
适用场景单一业务处理多监听、组件通信、插件同步

推荐：插件与核心内部同步使用事件；业务侧单一入口使用回调即可。
