项目介绍 ​

ew-color-picker 是一个基于 事件驱动 + 插件系统 的颜色选择器。核心包只做三件事：

  1. 维护当前颜色（currentColor）与 HSVA 状态（hsvaColor）；
  2. 通过实例级 EventEmitter 派发事件；
  3. 为插件提供 root 与 panelContainer 两个挂载点。

其余所有界面元素（颜色盒、面板、色相/透明度滑块、输入框、按钮、预定义色板、颜色模式切换器）都以插件形式注册，因此可以按需组合、自由扩展。

设计理念 ​

原则说明
单一数据源任何插件修改颜色都只调用 core.setColor()，再由 change 事件驱动其他插件同步，不存在多份颜色状态。
插件自治插件自己负责渲染、事件绑定与销毁，核心不感知具体 UI。
可裁剪不需要按钮就不注册 Button 插件；不需要透明度就不注册 Alpha 插件。
类型完备每个包都输出 .d.ts，插件通过 declare module 扩展配置类型。

包结构 ​

包职责
@ew-color-picker/core颜色状态、事件总线、插件注册与挂载点
@ew-color-picker/utilsDOM / 颜色 / 动画 / 事件 / 图标等基础工具
@ew-color-picker/style全部样式（index.css、input-number.css 等）
@ew-color-picker/ew-color-picker聚合包，注册全部内置插件，开箱即用
ew-color-picker兼容 v1 的无 scope 入口，转发聚合包与样式
@ew-color-picker/box触发面板的颜色盒
@ew-color-picker/panel饱和度/明度面板（核心必需插件）
@ew-color-picker/hue色相滑块
@ew-color-picker/alpha透明度滑块
@ew-color-picker/input文本输入框
@ew-color-picker/input-number数字输入框组件
@ew-color-picker/button清空 / 确定按钮
@ew-color-picker/predefine预定义颜色色板
@ew-color-picker/color-modeHex / RGB / HSL 模式切换
@ew-color-picker/eyedropper屏幕吸管取色（原生 EyeDropper API，Chromium）
@ew-color-picker/copy-color复制当前颜色到剪贴板
@ew-color-picker/console控制台版本横幅（已并入 utils）
