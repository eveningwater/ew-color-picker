Select 下拉选择 ​

@ew-color-picker/select 包含两部分：

  1. 插件 ewColorPickerSelect —— 在提供 selectItems 时，于底部行渲染一个下拉选择框；
  2. 组件 Select —— 可独立使用的受控下拉组件，供其他插件（例如渐变编辑器）复用。
项值
包@ew-color-picker/select
pluginNameewColorPickerSelect
applyOrderPost
挂载点panelContainer → .ew-color-picker-bottom-row（仅在有选项时渲染）
访问实例core.plugins.ewColorPickerSelect

需要额外样式

ts
import '@ew-color-picker/style/dist/select.css'
1

未引入时下拉框没有样式。

配置项 ​

配置类型默认值说明
showSelectbooleantruefalse 时隐藏下拉框
selectItemsSelectOption[][]选项列表；为空时不渲染
selectValuestring | numberundefined初始选中值
selectPlaceholderstringundefined未选中时显示的占位文案
selectClearablebooleantrue选中值后是否显示清空图标
onSelectChange(value, option) => void-用户选择后触发
onSelectClear() => void-用户清空选中项后触发
ts
import ewColorPicker from '@ew-color-picker/core'
import Select from '@ew-color-picker/select'

ewColorPicker.use(Select)

new ewColorPicker({
  el: '#app',
  selectItems: [
    { label: '线性', value: 'linear' },
    { label: '径向', value: 'radial' },
  ],
  onSelectChange: (value) => console.log(value),
  onSelectClear: () => console.log('已清空'),
})

插件方法 ​

方法签名说明
createSelect(options) => Select创建组件实例
updateOptions() => void重新读取配置并重新渲染
run() => void在有选项时渲染下拉框
destroy() => void移除下拉框并释放事件

import { Select } from '@ew-color-picker/select'

配置项 ​

配置类型默认值
valuestring | numberundefined
itemsSelectOption[][]
placeholderstring''
disabledbooleanfalse
size'small' | 'default' | 'large''default'
prefixstring'ew-'
clearablebooleantrue
onChange(value, option) => void-
onClear() => void-
onOpen / onClose() => void-

SelectOption 为 { label: string; value: string | number; disabled?: boolean }。

清空图标仅在 clearable 为 true 且已有选中值时显示。点击后会把值重置为 undefined、恢复占位文案、关闭下拉层并触发 onClear。禁用状态下不显示清空图标。

方法 ​

方法签名说明
getValue() => string | number | undefined当前值
setValue(value, triggerChange?) => void设置值；传 false 不触发 onChange
clear(triggerChange?) => void清空选中值；传 false 不触发 onClear
setItems(items) => void替换选项列表
setDisabled(disabled) => void切换禁用状态
open / close() => void打开 / 关闭下拉层
isDropdownOpen() => boolean下拉层是否打开
getElement() => HTMLElement根节点
destroy() => void解绑事件并移除节点

键盘与无障碍 ​

按键行为
ArrowDown / ArrowUp打开下拉层，或在选项间移动
Enter选中当前高亮项
Escape关闭下拉层
Tab关闭并移出焦点

触发器带有 aria-haspopup="listbox" / aria-expanded，选项使用 role="option" 并同步 aria-selected、aria-disabled。

  </button>

  </div>
