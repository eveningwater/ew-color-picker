Hue 色相滑块 ​

ewColorPickerHue 渲染一条 0–360° 的色相条。改变色相时保持当前饱和度、明度与透明度不变。

项值
包@ew-color-picker/hue
pluginNameewColorPickerHue
applyOrderPost
挂载点panelContainer
访问实例core.plugins.ewColorPickerHue

配置项 ​

配置类型默认值说明
huebooleantruefalse 时不渲染色相条（构造期生效）
hueDirection'horizontal' | 'vertical''vertical'滑块方向
disabledbooleanfalse禁用后点击/拖拽不生效

hue 与 ewColorPickerPanel

hue 只控制色相条本身，不影响二维面板。想要「极简取色」，通常同时关闭 hasPanel。

实例方法 ​

ts
const hue = picker.plugins.ewColorPickerHue
1
方法 / 属性签名说明
enableHue(enable = true) => void运行时显示/隐藏色相条，等价于 hasHue = enable
updateHue(hue: number) => void设置色相（0–360），内部经 core.setColor() 改色
updateHueThumbPosition(hue: number) => void只移动滑块，不改颜色
hasHueboolean（getter/setter）setter 会立即渲染或移除 DOM
hueBarHTMLElement | null色相条根节点
hueThumbHTMLElement | null滑块手柄
isHorizontalboolean当前是否水平方向

示例：运行时隐藏 ​

ts
picker.plugins.ewColorPickerHue.enableHue(false)
picker.plugins.ewColorPickerHue.enableHue(true)
1
2

交互行为 ​

操作行为
点击色相条按点击位置换算色相并立即改色
按住拖拽节流 16ms 连续改色
外部颜色变化监听 change，用新颜色的 h 同步手柄位置

色相条背景始终是完整的 360° 光谱，不受当前颜色影响。

事件 ​

改色通过 core.setColor()，因此：

ts
picker.on('change', (color) => console.log(color))
1

会收到色相拖动产生的颜色。Hue 自身不 trigger 额外事件。

完整示例 ​

ts
const picker = new ewColorPicker({
  el: '#app',
  defaultColor: '#ef4444',
  hueDirection: 'horizontal',
})

// 监听色相变化
picker.on('change', (color) => {
  const h = picker.hsvaColor.h
  console.log(`色相 ${h.toFixed(0)}°，颜色 ${color}`)
})

// 设置为 200°（青蓝）
picker.plugins.ewColorPickerHue.updateHue(200)
